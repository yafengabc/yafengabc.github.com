## 一、先选对版本：这一节值几十小时

这是整篇教程最不该跳过的一节。选错了，你后面的一切努力都可能白费。

### Steam 上到底要买哪两个东西

在 Steam（以及 Epic、官网）上，这游戏你买来买去就两个：

| | 本体 Elite Dangerous | Elite Dangerous: Odyssey（DLC） |
|:--|:--|:--|
| 是什么 | 基础游戏，已自带 Horizons | 资料片：On-foot 徒步、**外星生物学（Exobiology）**、地表战斗、一整代新船 |
| 怎么买 | 必买 | 建议买（理由见下） |

### 为什么强烈建议把 Odyssey 也买了

一句话：**只买本体照样能飞，但会错过当前版本对新手最友好的一艘船、一条最赚钱的赛道，以及一代新船里最关键的几艘。**

买 Odyssey 不只是为了下船走路——哪怕你只想开船，它也带来三样很实在的东西：

**1）当下最适合新手的那艘船，只有 Odyssey 玩家领得到**

Lynx Highliner（猞猁高级班轮）是一艘 **0 ARX 免费**的中型客轮，也是当前版本新手的最优解（第 5 章细讲）。但"免费"是有前提的：**它挂在 Odyssey 名下**，只买本体的账号在商店里连它的领取入口都看不到。所以"开局白拿一艘中型客轮神器"这个福利，是 Odyssey 玩家独享的。

**2）它独占一条最赚钱的赛道：外星生物学**

外星生物学是 Odyssey 独享的玩法，也是它真正的"摇钱树"：降落到星球表面、徒步走出去，用基因采样器采集外星生物样本，回工作站变现。一趟成熟的"探索 + 外星生物学"组合能轻松赚几千万 CR——这是**只买本体完全碰不到**的收入，也是新手最快脱贫的路子之一（第 7 章展开）。

所以 Odyssey 买的不是"能下船走路"，是多了一整条赚钱赛道。

**3）它还决定了一代新船里最关键的几艘能不能到手**

下面几艘是 2024–2026 年陆续加入的"新世代"飞船，整体把当前版本的体验拉高了一截。它们跟 Odyssey 的关系分三种：① **必须拥有 Odyssey 才能拿到**——Lynx Highliner、Kestrel Mk II；② **奥德赛玩家开放 CR 直购、但非奥德赛玩家需先用 ARX 解锁**——Corsair、Caspian Explorer、Type-8 Transporter、Type-11 Prospector；③ **有本体就能在船坞买**——Mandalay、Python Mk II、Cobra Mk V、Panther Clipper Mk II。先认个脸，你就知道"长大"后能开什么：

| 飞船 | 定位 | 核心优势 |
|:--|:--|:--|
| **Lynx Highliner** | 中型客运（奥德赛专属） | 0 ARX 免费领、船体永久免费，是开局即用的神器（详见第 5 章）；需拥有 Odyssey 才能领取 |
| **Kestrel Mk II（红隼）** | 小型战斗（需 Odyssey） | 核心动力 2026 新船，极速 + 极致机动、SCO 优化；纯空战/竞速专精，但内部空间与装甲做了取舍；需拥有 Odyssey 才能购买 |
| **Corsair（海盗船）** | 中型多用途 | Gutamaya 2025 出品，火力与货舱兼顾的真·多面手；奥德赛玩家 CR 直购，非奥德赛需先 ARX 解锁 |
| **Caspian Explorer（里海探索者）** | 大型探索 | Zorgon Peterson 2025 出品，SCO 优化、专精星球滑降与高重力推进；奥德赛玩家 CR 直购，非奥德赛需 ARX 解锁 |
| **Type-8 Transporter（8型运输舰）** | 中型货运 | Lakon 2024 出品，SCO 优化、最大载货约 406 t，填补 Type-7 与 Type-9 之间的货运档；奥德赛玩家 CR 直购，非奥德赛需先 ARX 解锁 |
| **Type-11 Prospector（11型探矿者）** | 中型采矿 | Lakon 2025–2026 出品，首艘专职采矿船，SCO 优化、预留采矿硬点与舱室；奥德赛玩家 CR 直购，非奥德赛需先 ARX 解锁 |
| **Mandalay** | 中型探索旗舰 | 跃迁距离惊人、地表探索手感顶级，原生 SCO 友好；是当前探索与外星生物学的首选船；有本体即可在船坞购买 |
| **Python Mk II** | 中型战斗 | 机动性极佳，劫掠、赏金猎杀、反异种皆强；是时隔六年的首艘新船；有本体即可在船坞购买 |
| **Cobra Mk V** | 小型全能 | 2025 年量产；客/货/战兼顾，是顺滑的新手过渡船；有本体即可在船坞购买 |
| **Panther Clipper Mk II** | 大型货运 | 非旗舰级最大货舱，首艘为 SCO 优化的大型船；大宗贸易的终极选择；有本体即可在船坞购买 |

> **一句话**：Odyssey 玩家开局白拿 Lynx、多一条外星生物学的印钞赛道，新船里最关键的 Lynx 与 Kestrel 更是非它不可、另有四艘非奥德赛玩家得多花 ARX。只买本体，等于把当前版本对新手最友好的两样福利直接放弃。

## 二、装汉化：等了十年的中文

### 这游戏官方没有中文

《精英危险》2014 年发售，官方**至今没有提供简体中文**。考虑到这游戏满屏都是天体物理名词、派系名称、模块缩写和任务条款，语言这道坎劝退的人，可能比操作难度劝退的还多。

民间汉化的历史挺曲折：

| 时间 | 事件 |
|:--|:--|
| 2016 | 贴吧玩家发布首个可用的 UI 汉化补丁 |
| 2017 | 汉化鼎盛期，覆盖界面、船械、任务、派系 |
| 2018 | Frontier 调整了字库与资源封包加密，汉化难度陡增 |
| 2019 | 多数汉化补丁彻底失效，汉化组陆续退出 |
| **2020–2024** | **汉化基本不可用**，中文玩家只能靠攻略、机翻和群里问人 |
| **2025 年末** | 核心玩家 **TowaNoah** 牵头重组汉化组，攻克封包与字库难题，**汉化复活**，并补齐了 Odyssey 的徒步任务、外星生物学、地面战斗文本 |

所以如果你是一两年前听说过这游戏、又因为"没中文"放弃的——**现在可以回来了**，情况已经完全不一样。

### 用什么装：EliteDangerousToolBox

新汉化配套的工具有个好记的名字：**EliteDangerousToolBox**（中文社区也叫它"精英危险汉化工具箱"或"中文汉化盒子"），2026 年 1 月发布 1.0 版。

它干的事就一件：**一键安装和更新汉化。**

你不需要自己去翻安装包、不用手动覆盖游戏文件、也不用担心版本对不上——打开工具箱点一下，它自己处理。汉化组每次更新词条（比如从 1.31 升到 1.3.3），你在工具箱里一键更新就行。

> ⚠️ **两点提醒**
> - 这是**第三方非官方工具**。请从中文社区的可信渠道获取——B 站汉化组账号、百度"精英危险"吧、中文维基的相关页面，或直接进汉化群。别在来路不明的下载站下。
> - **每次游戏大版本更新后，汉化可能需要等汉化组跟进**。如果某次更新后发现界面变回英文了，多半不是你装坏了，是汉化还没适配——等工具箱推更新即可。

**顺手加一个中文中队：进队真有福利**

中队（Squadron）就是这游戏的公会。加队不只是找人聊天——**不少中文中队会给萌新发实打实的福利**：每周从中队银行领一笔 CR，有的还直接送船（比如 Mandalay 这种中型探索船），帮你跳过最难熬的原始积累。

这不是段子，是系统支持的：2025 年 8 月「先锋」更新重做了中队系统，新增的**中队银行（金库）**能存信用点、飞船和商品，**信用点可以直接转给成员**——所以"每周发钱、送船"在机制上完全成立。

- **怎么加**：游戏内 **右侧系统面板（4 号面板）→ 中队（Squadron）**，按名称或 ID 搜索后发申请即可
- **去哪找中文中队**：中文中队的招新帖集中在百度"精英危险"吧、中文论坛（ed.spacedock.cn 的中队版块）；也可以在游戏内用**中队浏览器**按语言、时区筛选。教程不点名具体中队——既免广告嫌疑，也免得队伍变动后信息过时
- ⚠️ **福利因队而异，也会随版本和队内政策变动**：具体发多少 CR、送什么船，一律**以该中队最新招新帖为准**
- ✅ **加错随时能退**，退出后可自由加入别的队，没有惩罚

## 三、把画面调到"中文看得清"

这一节英文教程不会写，但对中文玩家是刚需。

### 问题出在哪

游戏里有个叫 **FSR（超级分辨率超分）** 的功能，原理是先按较低的分辨率渲染画面，再放大到你的屏幕分辨率。这样做能显著提升帧率——代价是**画面变糊**。

对英文来说，糊一点还能认。但**中文字笔画密、结构复杂，一糊就彻底没法看**。任务描述、模块说明、派系名称糊成一团灰边，玩十分钟就眼睛疼。

更麻烦的是，这个选项有时候是默认开启的，很多人压根不知道它存在，只觉得"这游戏字怎么这么难受"。

### 必改的四项

进 **选项 → 图像 → 质量**，照下面改：

| 设置项 | 改成 | 为什么 |
|:--|:--|:--|
| **图像缩放 / Upscaling** | **正常（Normal / None）** | 关掉 FSR，这是糊的元凶 |
| **抗锯齿 / Anti-Aliasing** | **SMAA** | 别用 FXAA——它是全屏模糊滤镜，中文最遭殃 |
| **超级采样 / Supersampling** | **1.25x–1.5x** | 真正的抗锯齿 + 锐化，中文最清楚。性能不够就退回 1.0x |
| **动态模糊 / 景深 / 泛光** | 关 | 进一步减少糊感和光晕干扰 |

> ⚠️ **改完必须重启游戏才生效。** 很多画面设置不会即时更新，改完看着没变化先别怀疑人生，重进一次。

### 帧率不够怎么办

关掉 FSR 后帧率会掉，这是正常的。掉帧时**按这个顺序砍**，别把 FSR 再开回来——那是拿可读性换帧数，中文玩家亏不起：

1. **超级采样** 退回 1.0x
2. **阴影** 降到中或低
3. **体积光 / 体积效果** 降到中或低
4. **特效质量（FX）** 设为中
5. 最后才考虑降分辨率

调的时候按 **Ctrl + F** 可以调出帧率显示，边调边看代价，比凭感觉猜准得多。

另外提一句：这游戏对 CPU 和内存带宽的敏感程度，高于对显卡的敏感程度。如果你在机库或地表掉帧严重，先别急着怪显卡。

> 注：不同版本的菜单中文译名可能略有出入（比如"图像缩放"也可能叫"缩放"或"超分"）。认准英文关键词 **Upscaling / Anti-Aliasing / Supersampling** 就不会错。

## 四、设备：鼠标键盘就能玩，但有个前提

### 最低门槛比你想象的低

鼠标键盘完全可以玩这游戏，很多老玩家也是这么起步的。

真正的前提不是设备，是**键位**：开局先花十分钟进设置，把这几个动作分清楚、记住：

- **油门**（前进/后退）
- **偏航**（机头左右）
- **俯仰**（机头上下）
- **横移**（左右平移）

这四组是最常用的。剩下的一时记不住没关系，用到了再查——但**这四组必须形成肌肉记忆**，否则每次遇事都要低头找键，非常容易出事。

### 想认真玩，考虑飞行摇杆

这游戏是为 HOTAS（手不离杆系统）/ 双摇杆设计的。飞行手感、精细操纵、沉浸感的提升是质变级别的，不是"好一点"。

但**别在还没确定自己喜不喜欢这游戏之前就买**。先用鼠标键盘玩个十来小时，确认要继续，再考虑投入。

## 五、三种模式：新手先别进 Open

游戏有三种模式，开局就要选：

| 模式 | 是什么 | 新手建议 |
|:--|:--|:--|
| **Solo（单人）** | 只有你 + NPC，世界照常运转 | ✅ **推荐** |
| **Private Group（私人组）** | 只有你邀请/加入的特定玩家 | ✅ 推荐（适合和朋友一起） |
| **Open（开放）** | 会遇到所有真人玩家，包括海盗 | ⚠️ 先别进 |

**Open 里的其他真人玩家是会真的打你的**，而且他们往往装备精良、技术熟练。新手开着初始船进 Open，被击毁是大概率事件。

连官方自己都在提示里说过：参与社区目标时想避开麻烦，就暂时别进 Open。

所以：**先在 Solo 里把基础操作、任务流程、赚钱路子摸熟**，等你对自己的船和操作有信心了，再考虑去 Open 体验真实的社交与危险。这不是胆小，这是顺序问题。
